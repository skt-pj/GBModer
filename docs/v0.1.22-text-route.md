# GBModer v0.1.22 — selectable processing routes

- UIで処理ルートを選択できる。
  - `MediaProjection（既存ルート）` — 既存の高速キャプチャ経路。
  - `Accessibility Window（Android 14+）` — AccessibilityServiceのウィンドウ取得経路。
- `文字認識・8×8再描画` は処理ルートとは独立してON/OFFでき、初期値はOFF。
- ON時は可視Accessibility文字列を取得し、既存のfont_min / Misaki 8x8レンダラーで再描画する。
- 文字再描画は既存仕様どおり GBモード + GB解像度（160x144）で実行する。
- Accessibility Windowで文字認識ONの場合は、文字プレーンを適用できるCPU処理経路を使用する。
- 性能ログには `text_recognition_enabled`、Accessibility WindowのCPU経路では `font_min_ms` と `font_min_nodes` も記録する。
