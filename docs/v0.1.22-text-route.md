# GBModer v0.1.22 — selectable text-recognition route

- Default OFF: existing image-filter-only route.
- ON: after the normal GB image filter, read visible Accessibility text and redraw it using the existing font_min / Misaki 8x8 renderer.
- The switch is shown in the app UI as `文字認識ルート`.
- Android 14+ `accessibility_window` and the older `media_projection` path use the same switch value.
- Text redraw is executed only for GB mode + GB resolution (160x144), matching the existing renderer constraint.
- Performance logs include `text_recognition_enabled`, `font_min_ms`, and `font_min_nodes` for the Android 14+ path; MediaProjection keeps its existing font_min timing fields and adds the enabled flag.
