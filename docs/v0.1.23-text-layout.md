# GBModer v0.1.23 — text layout and scroll synchronization

- Text replacement still uses Accessibility text plus the existing font_min / Misaki 8x8 glyph sources.
- Replacement glyph size is no longer fixed to one 8x8 logical tile per Android character.
- Each Accessibility text node is laid out in source-window pixel coordinates first, then nearest-neighbour mapped into the 160x144 GB framebuffer. This preserves the source node's apparent text size and compensates for the portrait window-to-GB framebuffer stretch.
- Parent text nodes with direct visible text children are skipped to reduce duplicate parent/child redraws.
- Accessibility Window text mode tracks scroll/window content revisions.
- A frame captured before a scroll revision is discarded before processing or presentation, and the overlay is hidden until a matching fresh frame is ready. This prevents old text positions remaining over the newly scrolled content.
- Performance logs include `content_revision` and `frame_drop ... reason=content_revision_*` evidence when stale frames are rejected.
